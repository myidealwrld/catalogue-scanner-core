# Blocked: Catalogue Discovery

This is not a standalone catalogue scanner yet. The production scanner's README identifies one universal HTT service, but its executable reader combines discovery evidence with proprietary textile/ingredient scoring, publication rules, private result datasets, and AWS Lambda deployment. The archived `Scans` directory is historical scan output, not an independent discovery implementation.

The inspected code does not establish a separable, safe implementation for sitemap traversal, pagination, JSON-LD extraction, Shopify discovery, or WooCommerce discovery. Recreating those paths here would invent functionality, which the extraction brief forbids. This copy therefore contains only an offline product-record normalizer and must remain **NOT READY** until a generic adapter is identified and independently tested.

No production AWS files, API endpoints, scan results, brand data, or scoring code were copied.
